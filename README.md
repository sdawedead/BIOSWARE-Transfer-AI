# BIOSWARE Transfer AI

A local workflow tool for turning transport-order messages into structured ride records.

The repository also contains an Android notification bridge prototype used to pass selected incoming order notifications to the local service.

## Highlights

- Message parsing into structured ride data
- Ride and weekly-summary workflow
- Local Python API
- Responsive browser UI
- Android bridge prototype
- Designed for private, local-network use

## Privacy

Real ride records, phone numbers, bridge tokens, logs and APK builds are not included.

## Stack

Python, JavaScript, HTML, CSS, Android / Java.
